# IsometricCube

`IsometricCube` renders a cube using a required size and depth. Its faces are child elements marked with the `IsometricCubeSide` directive.

## Import

```ts
import {
  IsometricCube,
  IsometricCubeSide,
} from "isometric-angular/isometric-cube";
```

Add both to your component's `imports`.

## Selectors

```html
<div isometric-cube [size]="{ width: 5, height: 5 }" [depth]="2">
  <div isometricCubeSide="top"></div>
</div>
```

| Selector              | Class               | Description                       |
| --------------------- | ------------------- | --------------------------------- |
| `[isometric-cube]`    | `IsometricCube`     | The cube itself (component).      |
| `[isometricCubeSide]` | `IsometricCubeSide` | Marks an element as a cube face (directive). |

## Inputs (`isometric-cube`)

| Input             | Type                                                | Required | Description                           |
| ----------------- | --------------------------------------------------- | -------- | ------------------------------------- |
| `size`            | `{ width: number \| string; height: number \| string }` | Yes      | Base cube dimensions.                 |
| `depth`           | `number \| string`                                  | Yes      | Cube depth.                           |
| `position`        | `Position`                                          | No       | Offsets and elevation values.         |
| `border`          | `Border`                                            | No       | Border styling for rendered faces.    |
| `shadow`          | `Shadow`                                            | No       | Shadow distance and spacing settings. |
| `shadowAnimation` | `ShadowAnimation`                                   | No       | Animated shadow configuration.        |
| `rotation`        | `Rotation`                                          | No       | Rotation animation configuration.     |

Put one element per face you want to see inside the cube.

## Inputs (`isometricCubeSide`)

| Input               | Type                                                                                | Required | Description                |
| ------------------- | ----------------------------------------------------------------------------------- | -------- | -------------------------- |
| `isometricCubeSide` | `"top" \| "front-left" \| "front-right" \| "bottom" \| "back-left" \| "back-right"` | Yes      | Which cube face to render. |

The directive only positions the element as a face (it adds an `isometric-cube-<side>` class). Background, text, and any other content are up to you.

## Basic usage

```ts
import { Component } from "@angular/core";
import {
  IsometricCube,
  IsometricCubeSide,
} from "isometric-angular/isometric-cube";

@Component({
  selector: "app-basic-cube",
  imports: [IsometricCube, IsometricCubeSide],
  template: `
    <div isometric-cube [size]="{ width: 5, height: 5 }" [depth]="2">
      <div isometricCubeSide="top"></div>
      <div isometricCubeSide="front-left"></div>
      <div isometricCubeSide="front-right"></div>
      <div isometricCubeSide="bottom"></div>
      <div isometricCubeSide="back-left"></div>
      <div isometricCubeSide="back-right"></div>
    </div>
  `,
})
export class BasicCube {}
```

## With optional inputs

```ts
import { Component } from "@angular/core";
import type { Border, Position, Shadow } from "isometric-angular";
import {
  IsometricCube,
  IsometricCubeSide,
} from "isometric-angular/isometric-cube";

@Component({
  selector: "app-styled-cube",
  imports: [IsometricCube, IsometricCubeSide],
  template: `
    <section
      isometric-cube
      [size]="{ width: 5, height: 5 }"
      [depth]="2"
      [position]="position"
      [border]="border"
      [shadow]="shadow"
    >
      <div isometricCubeSide="top"></div>
      <div isometricCubeSide="front-left"></div>
      <div isometricCubeSide="front-right"></div>
    </section>
  `,
})
export class StyledCube {
  protected readonly position: Position = { top: 2, left: 1, elevation: 1 };
  protected readonly border: Border = {
    size: 1,
    style: "solid",
    color: "#2f2f2f",
  };
  protected readonly shadow: Shadow = { distance: 2, spacingX: 1, spacingY: 1 };
}
```
