# Shadow Animations

Use `shadowAnimation` to animate shadow distance and create movement effects like hovering.

## Type signature

```ts
interface ShadowAnimation {
  from: string | number;
  to: string | number;
  spacingX: number;
  spacingY: number;
  delay?: number;
  duration?: number;
  options?: string;
}
```

## Supported components

- [IsometricCube](../components/isometric-cube.mdx)
- [IsometricPlane](../components/isometric-plane.mdx)
- [IsometricGrid](../components/isometric-grid.mdx)

## Example

```ts
import { Component } from "@angular/core";
import type { ShadowAnimation } from "isometric-angular";
import { IsometricPlane } from "isometric-angular/isometric-plane";

@Component({
  selector: "app-animated-plane-shadow",
  imports: [IsometricPlane],
  template: `
    <div
      isometric-plane
      [size]="{ width: 5, height: 5 }"
      color="cyan"
      [shadowAnimation]="hover"
    ></div>
  `,
})
export class AnimatedPlaneShadow {
  protected readonly hover: ShadowAnimation = {
    from: 1,
    to: 4,
    spacingX: 1,
    spacingY: 1,
    duration: 1.5,
    options: "alternate infinite",
  };
}
```

## Fields

| Field      | Type               | Description                                                                           |
| ---------- | ------------------ | ------------------------------------------------------------------------------------- |
| `from`     | `number \| string` | Starting shadow distance. Numbers are treated as `rem`.                               |
| `to`       | `number \| string` | Ending shadow distance. Numbers are treated as `rem`.                                 |
| `spacingX` | `number`           | Horizontal shadow direction multiplier.                                               |
| `spacingY` | `number`           | Vertical shadow direction multiplier.                                                 |
| `delay`    | `number`           | Delay before animation starts (seconds).                                              |
| `duration` | `number`           | Animation duration (seconds).                                                         |
| `options`  | `string`           | Additional CSS animation options, for example `"alternate infinite"`. Defaults to `"normal"`. |

`shadowAnimation` draws its own shadow, so you do not need to pass `shadow` as well.
