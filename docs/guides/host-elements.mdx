# Host Elements

Every component and directive in `isometric-angular` uses an attribute selector. Instead of rendering a wrapper element of its own, it attaches to the element you put it on, so you decide which HTML element ends up in the DOM.

This is the Angular counterpart of the polymorphic `as` prop in `isometric-react`.

## Selectors

| Selector              | Class                                                 |
| --------------------- | ----------------------------------------------------- |
| `[isometric-root]`    | [Isometric](../components/isometric.mdx)              |
| `[isometric-cube]`    | [IsometricCube](../components/isometric-cube.mdx)     |
| `[isometricCubeSide]` | `IsometricCubeSide`                                   |
| `[isometric-plane]`   | [IsometricPlane](../components/isometric-plane.mdx)   |
| `[isometric-grid]`    | [IsometricGrid](../components/isometric-grid.mdx)     |

## Example

```ts
import { Component } from "@angular/core";
import { Isometric } from "isometric-angular";
import { IsometricPlane } from "isometric-angular/isometric-plane";

@Component({
  selector: "app-host-elements",
  imports: [Isometric, IsometricPlane],
  template: `
    <figure isometric-root aria-label="Isometric scene">
      <section
        isometric-plane
        id="hero-plane"
        [size]="{ width: 8, height: 8 }"
        color="#4f8bff"
      ></section>
    </figure>
  `,
})
export class HostElements {}
```

## Combining with other directives

Because the shape is the element itself, event bindings, template references, and other directives work on the same element:

```ts
import { Component, signal } from "@angular/core";
import { RouterLink } from "@angular/router";
import { Isometric } from "isometric-angular";
import { IsometricPlane } from "isometric-angular/isometric-plane";

@Component({
  selector: "app-level-select",
  imports: [Isometric, IsometricPlane, RouterLink],
  template: `
    <nav isometric-root aria-label="Levels">
      <a
        isometric-plane
        routerLink="/levels/1"
        [size]="{ width: 4, height: 4 }"
        [color]="hovered() ? '#7aa7ff' : '#4f8bff'"
        (mouseenter)="hovered.set(true)"
        (mouseleave)="hovered.set(false)"
      >
        Level 1
      </a>
    </nav>
  `,
})
export class LevelSelect {
  protected readonly hovered = signal(false);
}
```

## Notes

- The host element controls which native attributes and events are available (for example `href` on links or `type` on buttons).
- Component inputs such as `size`, `depth`, or `position` work the same on every host element.
- Components project their content into the host, so choose an element that can contain other elements rather than a void element like `img` or `input`.
- The host keeps its native styles. Reset margins, padding, or borders for elements such as `button`, `ul`, or `figure` when they get in the way.
