# Borders and Edges

Use `border` and `edge` to add definition and depth to isometric surfaces.

## Type signatures

```ts
import type { Property } from "csstype";

type Length = number | (string & {});

interface Border {
  size?: Property.BorderWidth<Length>;
  style?: Property.BorderStyle;
  color?: Property.BorderColor;
}

interface Edge {
  depth?: string | number;
  color?: string;
}
```

## Supported components

- `border`: [IsometricCube](../components/isometric-cube.mdx), [IsometricPlane](../components/isometric-plane.mdx)
- `edge`: [IsometricPlane](../components/isometric-plane.mdx) only

## Border example (cube)

```ts
import { Component } from "@angular/core";
import {
  IsometricCube,
  IsometricCubeSide,
} from "isometric-angular/isometric-cube";

@Component({
  selector: "app-cube-with-border",
  imports: [IsometricCube, IsometricCubeSide],
  template: `
    <div
      isometric-cube
      [size]="{ width: 5, height: 5 }"
      [depth]="5"
      [border]="{ size: 2, style: 'solid', color: 'green' }"
    >
      <div isometricCubeSide="top">TOP</div>
      <div isometricCubeSide="front-left">FRONT LEFT</div>
    </div>
  `,
})
export class CubeWithBorder {}
```

On a cube, the border is drawn around every face. The border color is darkened slightly so faces stay distinguishable.

## Border and edge example (plane)

```ts
import { Component } from "@angular/core";
import { IsometricPlane } from "isometric-angular/isometric-plane";

@Component({
  selector: "app-plane-with-edge",
  imports: [IsometricPlane],
  template: `
    <div
      isometric-plane
      [size]="{ width: 8, height: 8 }"
      color="#4f8bff"
      [border]="{ size: '1px', style: 'solid', color: 'red' }"
      [edge]="{ depth: 8, color: '#2c4ea3' }"
    ></div>
  `,
})
export class PlaneWithEdge {}
```

## Border fields

| Field   | Type                           | Description                                                                         |
| ------- | ------------------------------ | ----------------------------------------------------------------------------------- |
| `size`  | `Property.BorderWidth<Length>` | Border width, for example `1`, `"1px"`, or `"0.125rem"`. Numbers are treated as `px`. Defaults to `0px`. |
| `style` | `Property.BorderStyle`         | Border style, for example `"solid"` or `"dashed"`. Defaults to `"solid"`.           |
| `color` | `Property.BorderColor`         | Border color value. Defaults to `#000`.                                             |

## Edge fields

| Field   | Type               | Description                                                                  |
| ------- | ------------------ | ---------------------------------------------------------------------------- |
| `depth` | `number \| string` | Visual depth of the edge extrusion. Numbers are treated as `px`.             |
| `color` | `string`           | Base color used to render the edge shading (darkened by 20%). Defaults to `#fff`. |
