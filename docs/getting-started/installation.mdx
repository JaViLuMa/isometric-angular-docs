# Installation

Install `isometric-angular` using your preferred package manager:

```bash
npm install isometric-angular
```

```bash
yarn add isometric-angular
```

```bash
pnpm add isometric-angular
```

## Peer dependencies

`isometric-angular` is intended for Angular 21 projects (`^21.2.0`). Make sure your app uses compatible versions of:

- `@angular/core`
- `@angular/common`

## Entry points

Each component lives in its own entry point, so your bundle only contains the components you import:

| Import path                        | Exports                                                     |
| ---------------------------------- | ----------------------------------------------------------- |
| `isometric-angular`                | `Isometric` and the shared [types](../api/types.mdx)        |
| `isometric-angular/isometric-cube` | `IsometricCube`, `IsometricCubeSide`, and the `CubeSides` type |
| `isometric-angular/isometric-plane` | `IsometricPlane`                                           |
| `isometric-angular/isometric-grid` | `IsometricGrid`                                             |

## Styles

There is no stylesheet to import. Each component ships its own styles, and Angular adds them to the page the first time the component renders.

The styles are not encapsulated (`ViewEncapsulation.None`), so the library classes and [CSS variables](../guides/css-variables.mdx) can be targeted from your own stylesheets.

The shared styles for positioning, borders, edges, shadows, and rotation are registered by the `Isometric` root component. Always render shapes inside an `isometric-root` element.

## Add the components

All components are standalone. Add the ones you use to the `imports` array of the component that renders them:

```ts
import { Component } from "@angular/core";
import { Isometric } from "isometric-angular";
import { IsometricPlane } from "isometric-angular/isometric-plane";

@Component({
  selector: "app-scene",
  imports: [Isometric, IsometricPlane],
  template: `
    <div isometric-root>
      <div isometric-plane [size]="{ width: 6, height: 6 }"></div>
    </div>
  `,
})
export class Scene {}
```

After that, continue with the [Quick Start](./quick-start.mdx).
