# Introduction

`isometric-angular` is an Angular component library for building isometric UI elements with clean, composable primitives.

It is inspired by the original [IsometricSass](https://morgancaron.github.io/IsometricSass/) approach, but designed for modern Angular applications with standalone components, signal inputs, and CSS-variable-based customization.

## Why isometric-angular

- **4 focused components**: `Isometric`, `IsometricCube`, `IsometricPlane`, and `IsometricGrid`, plus the `IsometricCubeSide` directive for cube faces
- **CSS variable driven**: tune visual appearance with custom properties
- **Attribute selectors**: put a component on whichever host element you need (`<section isometric-plane>`) and keep its native attributes, ARIA, and event bindings
- **Built for modern Angular**: standalone components, signal inputs, and `OnPush` change detection that work in zoneless apps
- **TypeScript first**: typed inputs that are checked in your templates with `strictTemplates`
- **Angular 21 compatible**: built to work with current Angular versions
